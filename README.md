Proyecto : Ametek Testing GTAO - GTSOC
Autor    : Oscar Tovar
ELRAD Electronics México
---------------------------------------------------------------------------------------------------
Desarrolla una solución para realizar las pruebas funcionales y eléctricas del producto del cliente según las especificaciones definidas en las **Especificaciones de Prueba (TestSpec)**. El objetivo 
es asegurar la calidad del producto, verificar el cumplimiento de los criterios de aceptación y mantener 
un registro de los resultados obtenidos de cada unidad inspeccionada, garantizando una trazabilidad completa.
